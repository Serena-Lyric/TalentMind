【TalentMind 前端正式集成说明】

正式源码位于 frontend/，由 A 统一接入后端 API。当前正式前端不使用本地 Mock 数据；无真实数据时显示空态或“暂无数据”。

页面：数据概览、JD岗位管理、全景能力图谱、简历解析匹配、技能学习路径、简历预览。

接口基础路径：/api；统一响应：{ code: 0, message, data }。
构建命令：pnpm run build。
开发命令：pnpm run dev。

- Jobs：读取真实岗位数据，写操作按后续 A/M5 联调清单验收；
- Resume：读取正式简历解析/岗位列表 API；
- Learning：等待 M4 pathfinder；
- ResumeDemo：等待最近一次解析结果状态传递。
