# 岗位能力图谱 - 前后端接口对接文档

> 前端：Vue 3 + Element Plus + ECharts
> 接口基础路径：/api
> 数据格式：JSON
> Mock 开关：src/utils/request.ts 中 USE_MOCK 字段

---

## 通用响应格式

`json
{
  "code": 0,
  "data": {},
  "message": "success"
}
`
