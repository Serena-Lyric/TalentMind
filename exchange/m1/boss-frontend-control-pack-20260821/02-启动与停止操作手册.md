# 02 启动与停止操作手册

## 人工前置条件

1. 启动独立 Edge，使用项目约定的独立用户目录。
2. 用户本人在 BOSS“我要投职”入口完成登录。
3. 确认 Edge CDP 端口 `127.0.0.1:9333` 正在监听。
4. 确认 CDP 页面目标中有 BOSS 求职页面，而不是只有 `edge://inspect` 或扩展后台页。
5. 不把密码、验证码、Cookie 或 `backend/.env` 交给前端或采集模块。

## 现有命令

以下命令从 `D:\Application\ClaudeCode\repository\TalentMind\backend` 执行。

### 单轮连通性验证

```powershell
.\.venv\Scripts\python.exe -m app.collect.boss_collect_loop `
  --cdp http://127.0.0.1:9333 `
  --user-data-dir "C:\Users\SERENA~1\AppData\Local\Temp\TalentMind-BOSS-Edge-9222" `
  --once
```

用途：只运行一个关键词/城市组合，验证 CDP、页面和入库链路。正常结束后 Python 进程退出。

### 有限轮数

```powershell
.\.venv\Scripts\python.exe -m app.collect.boss_collect_loop `
  --cdp http://127.0.0.1:9333 `
  --user-data-dir "C:\Users\SERENA~1\AppData\Local\Temp\TalentMind-BOSS-Edge-9222" `
  --rounds 3
```

用途：连续运行指定轮数。每轮只处理一个关键词/城市组合。

### 默认低速持续运行

```powershell
.\.venv\Scripts\python.exe -m app.collect.boss_collect_loop `
  --cdp http://127.0.0.1:9333 `
  --user-data-dir "C:\Users\SERENA~1\AppData\Local\Temp\TalentMind-BOSS-Edge-9222" `
  --forever
```

`--forever` 是命令自述参数；默认 `rounds=0` 也表示不设轮数上限。现有默认节奏：页面/详情间隔 15–30 秒，页面稳定等待 5–10 秒，关键词/城市切换 6–12 分钟；每轮最多 1 页、12 条岗位、8 条详情。

## 可调整参数

| 参数 | 默认值 | 用途 |
|---|---:|---|
| `--keywords` | 8 个默认关键词 | 逗号分隔的关键词 |
| `--cities` | 北京/上海/深圳 | 格式 `城市=代码` |
| `--pages` | 1 | 每个组合最多翻页数 |
| `--detail-limit` | 8 | 每轮最多补采详情数 |
| `--max-jobs` | 12 | 每轮最多入库岗位数 |
| `--page-delay-min/max` | 15/30 秒 | 列表/详情之间等待 |
| `--settle-min/max` | 5/10 秒 | 页面加载后稳定等待 |
| `--switch-interval-min/max` | 360/720 秒 | 组合切换等待 |
| `--rounds` | 0 | 0 表示不设上限 |

随机等待用于降低访问密度、避免固定节奏；不是也不能用于绕过安全措施。

## 停止方式

- 前台运行：在该终端按 `Ctrl+C`。
- 后台运行：由启动器记录 PID，按 PID 停止；不要按宽泛的 `python` 进程名停止其他项目。
- 采集器遇到 CDP/登录状态异常会返回退出码 2 并停止；普通单轮异常会记录后低频继续尝试。
- 停止采集后，Edge 是否退出登录由用户人工决定；不要由前端或后端处理凭据。
