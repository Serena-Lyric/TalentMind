# 06 数据指标与查询口径

## 采集结果指标

| 字段 | 口径 |
|---|---|
| `listed` | 列表页识别并纳入本轮处理的岗位数 |
| `details` | 本轮实际打开/尝试补采详情的岗位数 |
| `new` | 按 BOSS 来源 URL 去重后本轮新增写入 `jd_pool` 的岗位数 |
| `skipped` | 已存在 URL 或其他幂等原因跳过的岗位数 |
| `errors` | 本轮捕获并记录的异常数量 |
| `database_boss_total` | `SELECT COUNT(*) FROM jd_pool WHERE source='boss'` |
| `database_new_count` | 当前 BOSS 累计数减启动前保存的 BOSS 基线 |
| `latest_crawled_at` | BOSS 数据中最大的 `crawled_at` |

## 数据质量指标

建议在控制台提供“最近一次核验”而非每秒重算：

- BOSS `source_detail` 为空数。
- BOSS `source_detail` 重复数。
- BOSS 占位/空 URL 数。
- BOSS `duties` 非空数。
- BOSS `status` 分布。

## SQL 示例（仅供后端联调）

```sql
SELECT source, status, COUNT(*) AS n
FROM jd_pool
GROUP BY source, status
ORDER BY source, status;

SELECT COUNT(*) AS boss_total, MAX(crawled_at) AS latest_crawled_at
FROM jd_pool
WHERE source = 'boss';

SELECT
  SUM(source_detail IS NULL OR source_detail = '') AS empty_source_detail,
  COUNT(*) - COUNT(DISTINCT source_detail) AS duplicate_source_detail,
  SUM(duties IS NOT NULL AND duties <> '') AS duties_nonempty
FROM jd_pool
WHERE source = 'boss';
```

数据库列和表定义以 `backend/app/contracts/ddl.sql` 为准；前端不要直接依赖未冻结的数据库字段作为公开接口。
