# 05 后端现有资产索引

## 采集入口

| 资产 | 作用 |
|---|---|
| `backend/app/collect/boss_collect_loop.py` | BOSS 低速轮换循环；默认单关键词/城市、1 页、12 条岗位、8 条详情、15–30 秒页面间隔、6–12 分钟切换间隔 |
| `backend/app/collect/fetch_boss_jobs.py` | BOSS CLI 和列表/详情采集编排，负责去重后调用入库管道 |
| `backend/app/collect/fetchers/boss.py` | BOSS 列表/详情页面字段抽取、清洗和归一化 |
| `backend/app/collect/fetchers/cdp.py` | 连接用户人工登录的 Edge CDP，支持固定端点和动态端口发现 |
| `backend/app/collect/pipeline.py` | RawJD 清洗、去重、入库管道 |
| `backend/app/collect/repository.py` | `jd_pool`/signal 等数据库写入辅助逻辑 |
| `backend/app/collect/README.md` | M1 采集模块总说明 |

## 配置/运行资产

- CDP 默认端点：`http://127.0.0.1:9333`
- 用户数据目录参数：`--user-data-dir`，只用于连接/动态发现，不应交给前端作为凭据输入。
- BOSS 日志：`data/local/logs/boss_collect_loop.out.log` 和 `.err.log`（本地、gitignore）。
- 当前运行数据：`data/local/`，不随资料包提交。
