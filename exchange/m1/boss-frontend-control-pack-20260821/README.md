# BOSS 采集前端控制资料包

> 资料包日期：2026-08-21
> 目的：提供给前端用于设计 BOSS 采集控制界面。前端自行决定页面布局、组件和交互细节；本资料只约定现有能力、状态语义、进度口径和联调边界。
> 范围：资料整理，不修改后端代码，不新增控制 API。

## 先看什么

1. `01-当前运行状态.md`：当前是否在采集、数据库数量、CDP 状态和本次启动结果。
2. `02-启动与停止操作手册.md`：现有 CLI 启动方式、人工前置条件和停止方式。
3. `03-采集状态机与进度模型.md`：建议前端展示的状态、进度字段和状态转换。
4. `04-前端控制界面联调需求.md`：前端可设计的控制动作与后端待实现边界。
5. `05-后端现有资产索引.md`：代码、文档、日志和测试的位置。
6. `06-数据指标与查询口径.md`：采集结果字段、数据库统计和指标解释。
7. `07-本次启动记录-20260821.md`：本次单轮启动尝试的原始结果和核验结论。
8. `08-前端待确认问题.md`：联合设计时需要前后端共同裁决的问题。

## 重要边界

- BOSS 只能通过用户人工登录的独立 Edge + CDP 读取页面可见内容。
- 不接收、保存或处理密码、验证码、Cookie，不绕过登录、验证或反爬机制。
- 当前只有 CLI 和日志，没有已实现的 HTTP 控制接口、WebSocket 推送、暂停/恢复接口或任务编排服务。
- `pause`、`resume`、`refresh_status` 等动作在本资料中是前端联调语义，不代表后端已经实现对应 API。
- 资料包不包含 `backend/.env`、`data/local/`、`input/`、`output/`、账号信息、真实简历或 Cookie。

2026-08-21 已验证 BOSS CDP 页面可访问，单轮采集启动成功并正常结束；当前没有持续采集 Python 进程，9333 端口仍可用且有 BOSS 页面目标，系统处于可再次启动但未运行状态。
