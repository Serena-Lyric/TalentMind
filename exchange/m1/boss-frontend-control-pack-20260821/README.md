8. `08-前端待确认问题.md`：联合设计时需要前后端共同裁决的问题。

## 重要边界

- BOSS 只能通过用户人工登录的独立 Edge + CDP 读取页面可见内容。
- 不接收、保存或处理密码、验证码、Cookie，不绕过登录、验证或反爬机制。
- 当前只有 CLI 和日志，没有已实现的 HTTP 控制接口、WebSocket 推送、暂停/恢复接口或任务编排服务。
- `pause`、`resume`、`refresh_status` 等动作在本资料中是前端联调语义，不代表后端已经实现对应 API。
- 资料包不包含 `backend/.env`、`data/local/`、`input/`、`output/`、账号信息、真实简历或 Cookie。
