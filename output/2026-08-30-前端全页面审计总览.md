# TalentMind 前端全页面审计总览

- 审计日期：2026-08-30
- 审计对象：正式 `frontend/`、正式 FastAPI API、Neo4j 图谱接口，以及 `input/岗位能力图谱前端系统/`、`input/图谱模块/` 的可借鉴实现
- 审计方式：静态代码检查、真实 API 请求、Vite 本地代理、浏览器逐页访问和视觉检查
- 浏览器验证地址：`http://127.0.0.1:18080/#/`
- 后端验证地址：`http://127.0.0.1:18000/`

## 结论摘要

当前系统已经具备可演示的 MVP 外壳，但还不能称为“完整真实闭环”。主要原因不是页面数量不足，而是**真实数据、演示数据和空实现混在一起**：

1. Graph 页面是当前结合最成功的页面，真实读取 97 个节点、222 条边，并支持五种视图。
2. Jobs 页面能读真实 22 条岗位，但新增、编辑、导入、批量删除等按钮目前只是 UI 提示，没有调用后端写接口。
3. Dashboard 的统计卡片、趋势图、技能分布和岗位列表仍有大量硬编码演示数据；其中总岗位数实际为 22，页面却显示 2468。
4. Resume 页面能调用上传解析和岗位列表，但雷达图为空；目标岗位选择没有真正传给后端，后端会自行取最高匹配岗位。
5. Learning 页面没有真实数据源；ResumeDemo 页面直接访问空对象的嵌套字段，浏览器中表现为空白。
6. M2 的岗位关联问题和 M4 的 pathfinder 仍是上游阻塞项，不能由前端继续用 mock 掩盖。

## 页面验收矩阵

| 页面 | 浏览器状态 | 真实 API 状态 | 主要问题 | 责任人 |
|---|---|---|---|---|
| Dashboard | 可显示，视觉完整 | 仅概览卡片调用真实 API | 统计/趋势/岗位列表混用硬编码数据 | M5 + A |
| Jobs | 可显示 22 条真实岗位 | 列表真实；写操作未接 | 编辑、导入、删除、导出与字段筛选不闭环 | M5 + A |
| Graph | 正常显示 97 节点/222 边 | 图谱真实 | 聚焦、技术栈、级别、雷达、导出未闭环 | M5 + M3 + A |
| Resume | 上传入口正常 | 上传/目标岗位真实；雷达为空 | 目标岗位未传入、上传限制未校验、预览跳空白 | M5 + M4 + A |
| Learning | 当前空白/无业务内容 | 无真实学习路径请求 | `jobPaths` 永远为空，所有学习操作不可用 | M4 + M5 + A |
| ResumeDemo | 当前空白 | 无数据请求 | `resume` 初始化为空对象却直接读取嵌套字段 | M5 + M4 |

## 必须优先处理的 P0

### P0-1：禁止 Dashboard 展示虚假统计

实测 `/api/dashboard/overview` 返回：

```json
{"totalJobs":22,"totalResumes":0,"matchSuccess":0,"skillGaps":0}
```

但 Dashboard 页面显示 2468、8932、1847、376，并且趋势图和岗位列表也是固定演示数据。这个问题会直接影响答辩可信度，应优先改为真实数据或明确标记为“演示数据”。

### P0-2：修复 ResumeDemo 空白

`frontend/src/views/ResumeDemo.vue` 中 `resume = ref({})`，模板直接访问 `resume.basic.name`、`resume.education.school`、`resume.skills.details` 等字段。当前浏览器访问 `/resume-demo` 只有公共壳层，没有页面正文。

### P0-3：修复 Learning 空白并接通真实契约

`frontend/src/components/LearningRoadmap.vue` 中 `jobPaths` 初始为空，且没有调用任何学习路径 API。不能继续保留看似完整但永远没有数据的学习路线 UI。

### P0-4：Jobs 写操作必须真实执行或隐藏

当前“人工新增岗位”“保存岗位”“解析并导入”“批量删除”等操作只弹成功提示，未调用对应 API。对用户来说这是成功提示欺骗，应改为真实调用、明确“演示模式”，或暂时禁用按钮。

## 建议的实现顺序

```text
M5 修复空白页和假成功提示
  ↓
A 冻结 Dashboard / Jobs / Resume / Graph 的真实 DTO
  ↓
M2 修复岗位定义与 job_skill 关联
  ↓
M3 基于新 M2 数据重建图谱并更新 name_zh
  ↓
M4 实现 pathfinder 和标注测试集
  ↓
M5 接通 Learning / ResumeDemo / 雷达 / 趋势
  ↓
全链路验收与演示数据清理
```
