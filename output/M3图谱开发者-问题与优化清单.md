### M3-P0-02 固定图谱关系与节点字段

当前正式 API 将边类型转换为小写 `requires/related_to`，输入包布局使用大写 `REQUIRES`。前端已经做适配，但建议在 API DTO 中明确：

- `kind` 的枚举；
- `source/target` 使用英文岗位 key/canonical 技能；
- `label` 为展示名；
- `name_en/name_zh` 的优先级；
- `RELATED_TO` 明确是 Job–Job Jaccard 相似度，不是 Skill–Skill。

### M3-P0-03 为图谱生成加入数据质量门禁

至少检查：

- Job id 唯一；
- Skill id 唯一且 canonical；
- 每条边 source/target 都存在；
- `REQUIRES` 方向为 Job → Skill；
- `RELATED_TO` 两端均为 Job；
- 权重/相似度在合法范围；
- 没有空 label 和空 name。
