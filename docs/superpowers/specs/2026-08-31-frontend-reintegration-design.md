# TalentMind 前端完整重新整合设计

- 日期：2026-08-31
- 状态：已获用户确认并实施；2026-09-02 完成第一轮整体修复收口
- 范围：正式前端 `frontend/`、统一 API 路由、M1 采集控制台接入
- 视觉基准：`input/图谱.png`、`input/采集模块管理.png`
- 实施更新（2026-09-02）：Learning 在 M4 pathfinder 回包前，已按「中文岗位技能目录 + 简历内存态」实现确定性缺口/阶段生成（不 mock、不虚构课程）；本文第 3/4 节中“pathfinder / 无数据源空态”的表述仅指无可信数据源时的降级原则。

## 1. 目标

把前端开发者原版的页面能力与当前真实后端能力重新组装为一套唯一正式前端，消除多次补丁形成的导航、样式、Mock 和接口分叉。`input/` 仅作为对照与视觉参考，不作为运行时源码目录。

## 2. 页面与导航

正式导航固定为：能力动态更新、JD 岗位管理、采集图谱、数据分析、采集模块管理、简历分析、技能学习路径。测试页不进入正式导航；旧 `/graph-collection` 仅保留重定向到 `/graph` 的兼容入口。

统一壳层采用浅米白背景、白色圆角卡片、珊瑚色主操作、绿色成功状态和左侧固定圆角导航。图谱页单独采用深色星云画布，形成产品内有明确层级的“分析空间”。

## 3. 数据与接口原则

- 前端统一使用 `/api` 与 `{code,message,data}` 响应解包；不恢复原版 `fetch('/data/...')` 和硬编码 Mock。
- 图谱默认消费 `/api/graph/data`，岗位页消费 `/api/jobs`，Dashboard 消费真实 overview/trend/skill-distribution，简历页保留当前 PDF/DOC/DOCX/TXT 上传校验与目标岗位传参。
- 没有可信数据源的指标展示空态，不用演示数字填充；包括技能雷达、Learning pathfinder、能力动态无记录时的记录内容。
- M1 采集控制台以现有 `backend/app/collect` 为唯一采集实现，通过薄控制器提供任务状态、历史、CDP、数据库统计、配置和启动/停止包装；进入页面自动准备独立 Edge，已登录时仅尝试单轮，未登录只提示人工登录；持续采集仍需显式启动。

## 4. 实施边界

保留 A 已完成的真实 API、数据真实性降级、上传 422 修复、Pinia 最近解析结果和 Vite 18080 → 后端 18000 代理。重新实现 App 壳层、图谱星云交互、Collection 采集控制台、Analytics 数据页和 Evolution 只读页；Jobs、Resume、ResumeDemo、Dashboard 继续复用已联调能力并统一外层视觉。

不迁移 `input/人岗匹配/` 真实简历，不改变冻结 DDL 字段，不重写 M1 采集器，不删除 `input/` 原始对照包。

## 5. 验收标准

1. `frontend` 的 `vue-tsc` 与 `vite build` 通过。
2. 图谱可加载真实图谱、筛选岗位/技能/行业、搜索、缩放、拖拽、节点高亮和详情面板。
3. 采集控制台可显示当前状态、CDP 状态、数据库数据质量、历史任务；进入页面自动准备 Edge 并按登录态尝试单轮，持续采集仍通过 API 显式启动/停止；无 CDP 时给出明确错误。
4. 分析和能力动态页面只展示真实数据或诚实空态。
5. 正式导航不包含测试页面，不存在旧 `fetch('/data')` 或 mock 引用。
6. 资产清单和新增根因陷阱记录同步更新。
