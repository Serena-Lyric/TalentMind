- 日期：2026-09-04
- 状态：已获用户确认（先实现 A，看效果；效果不足再叠加 C）
- 目标：解决"学习阶段把所有缺口技能堆在一起"的问题，形成有先后顺序的路径感。
- 范围：`backend/app/routers/learning.py` 阶段生成 + `frontend/src/components/LearningRoadmap.vue` 阶段内展示；不改 DDL/契约/图谱。

## 一、分层规则（纯规则、启发式、可解释）
缺口技能按"学习性质"归入 4 个有序阶段（缺哪个跳哪个，空阶段不输出）：
1. 基础与工具（base）：编程语言、数据库，及 linux/shell/bash/git/powershell/sql/vim 等通用工具；
2. 核心框架与平台（core）：后端框架、前端技术、大数据/云、DevOps/运维、软件工程（排除通用工具）；
3. 岗位专项（advanced）：AI/机器学习、专业领域，以及未被归类/岗位特有写法；
4. 加分拓展（bonus）：加分技能缺口（放在最后，达标后再补）。

分类函数 `_phase_for(item)`：bonus 优先归"加分"；base/core 按类别与工具名；其余进 advanced。
说明文案如实标注：顺序为启发式推荐，非技能依赖图谱（图谱暂无 Skill–Skill 依赖边）。

## 二、阶段内有序展示（前端）
每个阶段卡片内不再用"标签云"，改为**有序步骤列表**：每条技能 = 序号 + 名称 + 类别标签 + 该技能的针对性建议（JD 证据/同类别衔接，来自上一版建议功能）。
阶段间按 1→2→3→4 呈现纵向步骤流。
