## 工程选择（实现者决定）

- 继续独立 frontend/visual-lab Three.js 候选；正式 Vue /graph 保持原入口。新候选默认消费 exchange/m3/graph.json，经 Vite 只读提供/构建时原字节打包。此为真实正式交接快照，不能称实时 Neo4j。
- ?data=demo 切回 116/40 合成适配；关闭候选直接返回原 18080/graph。新候选端口 18127，保护既有 18126 服务。失败明确报错，禁止静默回退演示。
- m3-adapter.js 为纯函数：保留逐节点/逐边原始索引、ID、类型与完整 raw；不解码/重写 legacy ID，不应用离线修复映射。异常 ID、重复节点、悬空边、未知类型拒绝加载。正式图既有语义缺陷如实披露。
- 布局仅为确定性展示：岗位按原 ID 哈希落在旋臂，技能/行业参照实际邻接岗位定位加微扰，不生成职业分类或社区。M3 模式不显示八个演示职业标签。装饰 214200 粒子完全不参与知识图计数/命中。
- 节点/关系类型与文本筛选采用诱导子图；搜索结果可选择，点击原位高亮；详情显示原 ID、JSON 索引、来源字段与历史要求语义。全部关系保留，曲线批处理绘制，邻接关系明确高亮。不新增知识边。
- P1-A.2 从原 P1-A 粒子大小/透明度/Shader 出发，只对旋臂宽度、偏移、局部密度和少量独立星点分布做有限变化；不增加粒子总数、Bloom、曝光、背景、雾光面积或模糊通道。P1-A.1 仅通过 Git replay 作为历史比较。
