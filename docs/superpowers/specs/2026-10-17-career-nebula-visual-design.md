# TalentMind · Career Nebula 视觉与交互设计基线（2026-10-17）

> **状态：已确认原则与第一轮页面边界；视觉细节及知识布局算法待设计。** 这是一份约束 Codex 与成员的产品/视觉规范，不是当前系统已完成效果的声明。权威产品裁决见 [PRODUCT_DECISIONS](../../PRODUCT_DECISIONS.md)；工程现实见 [M3 README](../../../backend/app/graph/README.md) 和 [PR #23](https://github.com/Serena-Lyric/TalentMind/pull/23)。本轮先设计、分阶段原型、真实截图验收，不授权直接重写正式图谱。

## 1. 已确认的目标与基线

- 整体视觉目标：**一片大型、连续、多色的知识银河**。以《诗云 · Poetry Cloud》的**程序化粒子、空间密度/纵深、星核、辉光和连续星云氛围**作为第一轮主要视觉参考。先忠实分析该作品的视觉语言，后逐项修改成 TalentMind 自己的作品；不允许仅根据“科技感/星云感”自行设计全新风格。
- **仅参考《诗云》的可验证视觉技术和表现方法**，不照搬其 React UI、诗人/诗歌数据模型、朝代径向分布、自由飞行作为 TalentMind 默认操作，也不抄录受许可约束的源码、纹理、媒体资源。可学习方法并独立实现；直接重用第三方代码必须先核对许可证、发布用途、依赖与授权。该项目现行许可证为 PolyForm Noncommercial 1.0.0，不能因仓库可见就假定可任意复制或商用。
- 继续保留 TalentMind 的 **Vue 3 应用、左侧浅色导航外壳、深色图谱主画布、真实 M3 数据与原有登录体系**。现有 Canvas/PR #23 留作对照与回退，是否换引擎是独立验收后的工程决定；**Three.js/WebGL 是重点候选路线，不等于已完成或必须全面替换**。不为新原型引入 React。
- 当前原版实际截图是界面骨架和操作基线；用户分享的两张星系短视频截图是审美参考；《诗云》仓库里的截图/运行效果是外部参考；**三者不是同一类证据，不得冒充 TalentMind 真机结果**。
- 演示优先：突出视觉质量与清晰的知识解释，只需目标桌面机基本流畅；出现明显卡顿再定位性能瓶颈，而不是先牺牲画面效果追求极限吞吐。

## 2. 第一批已确认页面改动（只作用于 /graph）

以现有左侧浅色应用导航卡片为基准：

1. **移除图谱页上方全局顶栏显示**：面包屑 `岗位能力图谱 > 岗位星云图谱`，以及右上 `系统运行中`、信息图标、`admin · 管理员`、退出按钮等**该顶栏的可视内容**。这是`/graph` 路由的单页处理，不得顺手删除其他页面的顶栏或退出机制。仍保留登录页、路由鉴权、用户状态与注销逻辑。今后把账户/设置入口统一放入设置的方向已确认，但**设置的结构、入口、迁移时机待定，本轮不实施**。
2. **右侧图谱主窗口上下边缘与左侧导航卡片视觉对齐**：首屏桌面（以用户实际截图宽屏为基线）图谱容器的顶部与底部对齐左侧侧栏卡片的可视边界，保持适度、一致的外边距；不是将图谱内部“节点详情面板”强制撑满导航高度。不能因移除顶栏留下 74px 空白、重复顶部留白、底部裁切或页面无意义纵向滚动。
3. **暂时完整保留图谱内部左右两侧菜单**：左侧搜索、类型筛选、图例、重置与刷新；右侧当前节点详情面板按选中状态出现。菜单中的布局/间距、文字和组件下一批再讨论。保留图谱内部 `岗位星云图谱 · Career Nebula` 标题及节点/关联数量，**其最终形态待后续单独决定**；不要把“移除页面面包屑”误解为“删除图谱内标题”。
4. 保留左侧全局导航（模块、图标、排序与宽度），不借这轮修改其他业务页面；只做图谱路由的特定外壳和容器对齐处理。无数据、加载失败、窄屏、放大缩小及固定左侧栏时仍可用。

## 3. 已确认的交互规则（后续渲染器也必须复现）

- **单击=原位选中**：不改变用户当前相机/视角，突出该节点真实直连并显示详情；点击空白/关闭详情不强制全览。
- **查看全部关联**由明确可见的独立操作触发：才可以临时调整视角以纳入完整可见邻域，并支持**返回进入关联前的原视角**。保存/恢复相机状态应有明确生命周期。
- 搜索结果可前后切换；Enter 下一条、Shift+Enter 上一条；搜索定位按需平移到目标，不强制将邻居全部塞入视野。
- 远景搜索命中要能辨识；放大后岗位、技能、行业/场景都有名称，按密度做可读性控制；节点不得无限随缩放放大遮挡标签。标签和交互命中不能把装饰星尘当成真实节点。
- 支持全览、拖拽/缩放与显式复位；新的三维实现默认可使用**近正面 2.5D 操作**，自由旋转只作为**待设计的显式可选功能**，不是默认强制漫游。
- 现有 [PR #23](https://github.com/Serena-Lyric/TalentMind/pull/23) 实验实现提供交互借鉴和回退基线，**仍为 Open，尚未合并/未获最终视觉验收**；不要直接以 PR 分支代码覆盖 master。

## 4. 可信图结构、可视聚合与粒子严格分层

- **事实层（M1/M2）**：招聘 JD、时间/版本与原文证据；M2 负责事实判断、条件组合、可信状态与统计口径，不得由 M3/M5 重新宣称业务事实。
- **图计算层（M3）**：基于真实 M2 事实组织岗位、技能、场景等实体的可计算知识关系；潜在关联和社区仅是计算推断，不直接写回已核实事实或当作职业晋升建议。
- **空间投影层（M3→M5）**：真实 `node_id`、`edge_id/source/target`、推断社区/重要性、确定性坐标与可视层级；任何真实节点/边需能追溯到真实输入 ID；远景合并或 LOD 隐藏**不是丢失/新增事实**。
- **渲染层（M5）**：真实节点粒子、星云装饰粒子、柔和辉光、标签与交互互相隔离；装饰星尘不是业务节点，不能计入图谱顶部数量、参与搜索/关联/统计或用于虚构关系。
- 图谱现有交接快照为 **7,845 节点/11,412 关系**（717 岗位、4671 技能、2457 行业/场景），**只是历史文件快照，非实时库或新版 M2 结果**；PR #21 只修了离线构建算法，新 ID/冲突字段的生产消费与迁移未授权。旧数据中的少数高共享技能与大量度为 1 的叶子节点会导致原始力导向图成团，原型需优先研究群落骨干 + 共享能力 + 私有技能/场景的分层空间表达，不要任意让全部节点落入“漂亮螺旋臂”。
- 视觉形态以大型连续多色银河为目标；实际社区数、分群算法、群落间距、颜色编码（实体类型/推断群落）、真实节点层级与辉光参数**均仍待可解释方案和视觉验收，不得擅自作为既定产品事实**。

## 5. 前端组件与 Codex 行为约束

- **优先使用现有成熟组件库**：现有 Vue 3 / Element Plus 基础按钮、输入、弹层、滚动与表单；既有 ECharts 负责普通统计图。绘图可研究 Three.js/现成图布局工具，但需要说明采用原因、维护成本与 Vue 集成方式；不得为了“炫酷”自行手搓基础表单、弹窗、路由、复杂布局引擎。
- 前端总体视觉样式由用户确认；Codex 不可擅自更换浅色系统外壳、整页暗黑霓虹管理台、导航结构、配色语义、右侧详情信息结构或业务图谱关系。
- 每一轮只做已经授权的范围，优先提交对照截图供用户反馈。先提交设计/可运行的**独立预览**，再决定正式集成。**高视觉相似性并不表示可以直接使用《诗云》的原始代码**。
- 真机截图与录屏必须标注：来源（正式页面/独立实验原型/外部参考）、实际数据版本、分辨率/视角、是否启用 LOD/装饰；不得使用 AI 概念效果图充作实现截图。
- 不能随意复制依赖版本到正式前端，也不能擅自启动大规模采集、真实数据写入、MySQL/Neo4j 迁移、图谱正式重建或删除工作树。
