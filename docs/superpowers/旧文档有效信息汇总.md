## 三、优先考虑的技术选型（仅参考，非约束，见 D5）

旧计划中出现的选型，新实施计划不再写死，作为优先考虑：

- 后端: Python 3.11 + FastAPI + SQLAlchemy + Pydantic v2 + pytest（已有骨架）
- 前端: Vue3 + TypeScript + Vite + G6/ECharts + Element Plus（M5 自选）
- LLM: OpenAI 兼容 API（文本 + 多模态）、embedding（经 llm.client 封装）
- 图谱: Neo4j 5 + Cypher（A 机器 docker）
- 采集: httpx + BeautifulSoup + Playwright（按源自选）
