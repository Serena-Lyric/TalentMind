## 2. P1：《诗云》视觉技术复现样品（独立入口；严禁直接替换正式图谱）

**设计目标**：以《诗云》真实代码及画面为明确基准，先研究并实现视觉相似的粒子、银河空间、星核、细腻光晕与亮度分布。**先做接近原参考的独立技术样品，再与 TalentMind 知识图谱结合**，不由 Codex 即兴设计新的“霓虹仪表盘”或堆积 3D 球体。

**阅读源**：作者项目 [Cohenjikan/shiyun](https://github.com/Cohenjikan/shiyun)、`src/three/Galaxy.tsx`、`galaxyParams.ts`、`positions.ts`、`PoetStars.tsx`、`docs/DEVLOG.md`；作者真实视觉参考 `docs/assets/hero.jpg`、`docs/assets/galaxy.jpg`、网站 `shiyun.cohenjikan.com`。若不能访问外部仓库或真实图像，必须**停下来明确说明**，不可将概念占位图或人工假图当作原作截图。
- 先交付半页以内的**算法/组件对照**：`THREE.Points + BufferGeometry`、稳定位置、粒子密度/噪声、暖色星核与多色星区、AdditiveBlending/Shader/Bloom、装饰与真实节点分层；注明哪些是原作观察、哪些是自主实验。
- 在不复制其源码/图像/纹理/诗歌资源的前提下，独立实现 Vue 3 兼容的 **WebGL/Three.js 单一可运行视觉样品**，仅供本地展示和审查。项目源代码现在是 PolyForm Noncommercial，不能因为公开就照搬。新增依赖前审查许可证/版本/体积；有可用成熟方案就复用而不重新写通用 3D 引擎。
- 参考图的**宏观视觉构图**：一片大型、连续、多色银河；不是多个散开的卡片式星团，也不是满屏大小相同的发光圆球。真实知识层稍后再接入，第一阶段视觉样品可以用**明确标记的纯装饰粒子**，但不能声称其位置是实际岗位社区。
- **近景尺度**：光点可随视距变化，但业务节点未来须有屏幕半径上限；远景层次、星核、星团与薄雾可读。让星尘与主要恒星视觉分离，不用背景粒子冒充真实知识节点。
- 先交付一张可复现的真实浏览器全景截图、一张局部放大、短视频（如可用）、操作 URL/启动命令、画质切换或测试记录。所有演示图须标明**独立样品，不是 TalentMind 正式页面**，提供与原作截图的逐项差异说明。
- 本阶段不要求一次接入全量 7845/11412 图谱，也不必完成搜索、社区、关系连线和相机飞行；这样避免“因业务节点布局太难，先把视觉风格也做错”。先由用户确定视觉质感，再推进 P2。

## 4. 独立验证与交付协议

| 门禁 | P0 外壳 | P1 视觉样品 |
|---|---|---|
| 范围 | 图谱路由专属外壳，不改其他页逻辑 | 独立 URL/组件，不替换正式图谱 |
| 构建 | `pnpm run build` 及针对性测试 | `pnpm run build`，许可清单与样品启动 |
| 视觉证据 | 真实 1600×900、1920×1080 同机截图，首屏两端对齐 | 原作截图链接 vs 本地真实样品截图，远景/近景 |
| 操作验证 | 登录、退出、其他页顶栏、左右图谱菜单 | 可载入、放大/缩小、主场景不崩溃，普通桌面机不明显卡顿 |
| 回退 | 小提交 + PR，不合并即不影响 master | 只在独立预览入口，不改主页面 |
| 用户验收 | **必须**在推进 P1 前进行 | **必须**在推进业务图谱集成前进行 |

Codex 每轮在 `docs/review/` 保留阶段报告、测试命令/运行结果、截图实际路径、基线 HEAD、未决事项；最终合并前遵守 [AGENTS](../../../AGENTS.md) 将长期结论归档并移除临时 review。无远端 CI 时不得声称远端测试已通过；无本机真实截图时不得声称页面视觉已验收。

**完成定义**：P0 与 P1 分别可独立审查、独立回退；没有偷偷修改登录、其他模块或正式图谱；视觉样品确实参照作者代码和画面，且无许可证违规直接复制；后续原型 P2 等待用户新决定。开发 PR 只由 ChatGPT 复审和用户授权后合并，Codex 不自动合并。
