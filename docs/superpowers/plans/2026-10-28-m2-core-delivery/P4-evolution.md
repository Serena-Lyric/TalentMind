# P4 — 候选自动演化、反证纠正与关键结构确认

> 状态及提交记录仅维护在 [总进度表](../2026-10-28-m2-core-delivery-plan.md#3-分段地图与当前进度)。直接依赖：P3 持续候选、P0 演化序列与 P1/P2 实际分析/标准版本。

**目标：** 新证据到来后共同职责和岗位解释自动更新生效，能说明为什么改变，并允许被推翻；人工参与仅保留在关键知识结构决策上。

## 最小阅读与输入

- [总计划](../2026-10-28-m2-core-delivery-plan.md)、[审核标准](../../specs/2026-10-28-m2-delivery-review-standard.md)、[设计 §6.2～§8、§11](../../specs/2026-10-28-m2-analysis-candidate-design.md)、产品 M2-64/M2-70。
- P3 的基准候选及冻结成员，包含新增支持、反证、原先误关联、标准更新、模糊混合与需要合并/拆分的序列。

## 必须交付的结果

1. 本批关联先使用一致的旧基准，再结合原成员与新证据重新归纳。证据充分且仍合理解释原组合与成员时，自动修订、生效并供后续比较，无人工接受前置。
2. 共同职责的语义变化本身不触发审核；新描述不反向自证本批关联，也不能仅依上次摘要反复改写而脱离源证据。
3. 支持、削弱、纠正与推翻能够改变判断及未决原因；不能融入的证据保留疑点，可建议拆分或新候选，不强行泛化旧描述。
4. 保留实际比较版本及重要改变理由，区分新招聘内容、知识标准和分析器变化；日常文字调整不生成繁琐审批记录。
5. 合并、拆分、正式归属、新岗位定义确认与正式发布由系统给依据、人工确认后才产生对应结构/正式效果；无确认仅保存建议。
6. 自动生效、人工确认、正式知识状态分别可见。关键确认绑定实际版本，过期决定不能作用于已变化对象；不建设两套工作流或复杂权限平台。

## 必须实际检查的行为

- [ ] 新增合理证据使描述自动生效，下一批确实使用新版本；无需逐条或逐次人工接受。
- [ ] 同批前后输入不会因中途摘要更新遇到不同基准；新摘要不能成为本批成员接纳的自证依据。
- [ ] 为容纳冲突而不断扩张到“软件开发”等空泛描述的情况被识别，原成员解释和反证仍可核查。
- [ ] 新岗位标准解释了原疑点时理由更新；候选结束正式独立观察/正式归属遵守人工确认边界。
- [ ] 未确认合并/拆分不改变身份；确认后的身份去向和旧判断可追溯，旧决定不跨版本静默套用。
- [ ] 原假设被推翻时不会删除原始事实或伪造真实市场变化。

## ChatGPT 审核与交接

审核真实调用链是否自动应用修订，以及与 P0 参照相符的连续序列；不能只验版本号变了或审批按钮存在。拒绝把稳定性要求重新包装成共同职责人工批准。

交接给 P5：实际更新/读取入口、比较基准版本、重要历史与原因记录、关键确认的真实操作与版本约束。模型、归纳算法和内部组织可替换，以可验证效果为准。提交独立 PR、序列证据和已知失效边界。

## Issue #67 限定范围实施计划

> **For agentic workers:** 使用 `executing-plans` 在本次会话连续实施，按下列检查项验证；不等待技术方案预审批。[Issue #67](https://github.com/Serena-Lyric/TalentMind/issues/67) 是本段自主实施、提交 PR 和评论回报的授权依据。

**Goal:** 自动重建可回源、可撤销的研究解释，并让后续批次实际比较该解释所绑定的有效证据。

**Architecture:** 复用 P3 的整批 SQLite 事务与稳定候选身份。增加确定性的源证据投影：逐个成员保留完整工作上下文、局部覆盖、字面共同陈述、疑点及排除依据；不做开放中文同组认证。`research` 是有效机器解释，旧 `description/core_work` 保留为调用方显式输入的研究标签/种子。后续检索使用有效投影的工作引用，仍只产生待研究线索，不能因链式检索升级为同组。

**Tech Stack:** Python 标准库、已有 Pydantic/P1/P2-1、隔离 SQLite；无新增依赖/模型调用/生产迁移。

**Spec:** 本页目标、Issue #67、产品 M2-61～71；真实语义缺口留在 #63。

### Global Constraints 与实现取舍

- 原分析、种子、旧批次和关系不覆盖；机器假设、受控支持、未认证外部材料、人审和正式身份分别表达。
- 只有同一冻结基线参与本批比较；自动投影在全部关系操作后生效。本批新增职责不能反向自证本批关联。
- 共同陈述仅作逐字职责交集，不称语义共同核心；未共同覆盖的职责逐成员展示，不抽象成空泛职业。
- 反证/撤回及竞争分析退出有效检索依据，原引用与历史成员继续可读；partial 的有效局部仍可研究。
- 来源独立性保持 unknown，转载不增加独立支持；无 JD 数量晋级门槛。知识重评回读旧成员，明确是研究重解释。
- 技术取舍：自动源证据投影可离线复核；开放模型归纳缺本阶段外发/费用和语义真值依据；仅增加摘要字段不能证明下一批生效。
- 关键结构只提出绑定候选/关系确切版本的建议；当前无可信人审身份链，不提供确认写入入口。
