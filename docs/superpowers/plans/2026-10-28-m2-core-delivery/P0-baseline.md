# P0 — 冻结中文评价基准与最小语义契约

> 当前状态、PR 与审核/合并提交以 [总进度表](../2026-10-28-m2-core-delivery-plan.md#3-分段地图与当前进度) 为唯一依据。一次新工作对话只完成本段；本文件不是已建成的数据集或已批准的模型配置。

**目标：** 后续实现与 ChatGPT 审查有同一套可检查的输入、预期、口径和契约，避免写完实现后再挑有利样本或重定义通过条件。

## 必须交付的结果

1. 一份可定位的私有评价清单：成员身份/内容摘要、来源、用途、版本、授权、标注/复核状态；选少量代表性真实中文 JD，数量由覆盖决定，实际数量如实记录。
2. 覆盖职责、要求逻辑、关系三态、岗位解释、候选配对与分批演化的参照案例；可先用合成案例验证读取，但真实语义指标必须对应真实人工参照。
3. 开发/留出用途划分及泄漏检查；人类标注可增加机器漏项。标注缺失/争议的项目显式待定，不用 Agent 或同模型未经审核输出填充人类真值。
4. 按审核标准冻结指标、分母、目标/定性通过条件及确认来源；未取得确认的指标保持未冻结，不声称本段语义条件已完备。
5. 最小语义契约：合法输入、职责/要求/关系及证据、部分/未知/失败、岗位解释、候选/正式性质和版本关联。具体编码/字段可由实施者提出，但必须可校验、可供 P1/P2 使用，并记录契约版本。
6. 形成实际权限核对记录：可用模型/运行方式、运行主体/服务、允许发送的真实数据范围、脱敏与材料提供方式、费用/调用上限及确认来源；未知项标待确认。没有外部发送授权时准备离线材料即可，不调用真实文本服务，不把候选技术选择写成永久产品规则。
7. 向 P2 交付少量可用的岗位参照定义：参照 ID、名称、核心职责/交付目标、已知范围和未明确边界、来源与定义版本、用途及知识状态。允许测试/候选标准，不要求先建完整正式目录；只有具备逐项批准证据的条目才能标正式。AI 草拟须标明起草性质与参考依据，不充当已确认职业边界。

## 人工参照、ChatGPT 可复核方式与权限前提

- **复核责任：** 负责人负责落实实际人工复核人，由本人或其明确指定的成员复核少量真实中文样本。P0 记录实际复核人、范围、时间、修改与争议状态；未落实就写未落实，不能预填署名。Codex 可整理待复核标注和错误对照，但 Agent 自检、模型生成或 ChatGPT 代码审查不自动成为人工真值。
- **受控复核材料：** 在既有私有评价清单中关联样本 ID/输入版本、保留作用域所需的中文上下文、逐项人工标签与理由、实际复核记录，以及后续预测/错误对照。由负责人确认可向 ChatGPT 提供的必要摘录、脱敏方式和提供渠道；不默认允许公开 GitHub 上传原始 JD，也不另建标注平台。
- **可核查范围：** 摘录不足以判断条件、否定或遗漏时补足经允许的上下文；只能查看部分内容时明确其覆盖范围，不能据此声称完整召回。关键原文或标注无法受控查看时，ChatGPT 报告相关语义证据不足，保留可检查的工程结论，不以路径、哈希或 Codex 自述替代语义核验。
- **模型与数据许可：** 本轮仅有计划/文档授权，未新增真实 JD 外发或付费模型许可。P0 启动时核对实际已有授权，缺少的由负责人明确；凭据存在、服务可访问或旧配置有模型名均不等于本次许可。需明确允许的数据、目标服务/模型范围、费用是否允许及上限，再执行对应真实调用；不具备条件时保留离线工程材料，并将真实语义验证条件列为未具备。

以上责任、岗位参照与许可在 P0 中实际落实并交接；本次只把要求写入计划，不准备真实样本、生成岗位定义或发起模型调用。

## 结果检查与 ChatGPT 审核重点

- [ ] 另一执行者能按清单取得同一输入及知识版本；私有路径失效有明确诊断，不静默换数据。
- [ ] 基准包含短 JD、未知词、开放任选、否定/优先作用域、同技能不同责任、同责任不同栈、目录缺口及反证序列。
- [ ] 人工参照来源与工程自检分开，未标注内容不会进入真实准确率分母。
- [ ] 实际人工复核人和 ChatGPT 可查看的材料/渠道已明确；不可查看部分如实标为证据不足，不通过公开上传私有全文解决。
- [ ] P2 所需的最小岗位参照可读取，来源、版本和测试/候选/正式状态可查；未覆盖边界不会被写成排除证据。
- [ ] 模型运行、真实文本发送和费用许可已逐项核对；未确认项和受影响的真实验证明确列出。
- [ ] 指标不能靠全未知通过；原文确实模糊时有合法未知预期。
- [ ] 契约支持独立单条分析与部分结果，不要求先有标准岗位名、M3 或完整职业目录。

## 本段自主范围与交接

可选择标注格式、样本读取方式、契约表达与评价工具；不以特定 JSON 字段名或工具为验收条件。业务阈值、真实文本外发和具体正式岗位批准仍需真实确认，不用规划代替授权。

交接给 P1/P2：冻结清单与摘要、实际人工复核与争议状态、ChatGPT 可复核材料及限制、最小岗位参照及来源/版本/知识状态、评价口径、契约版本、模型/数据/费用授权记录和实际读取方式。实际文件和命令写入本段交付报告；状态和审核/合并提交仅更新总表，本段结束不自动开始 P1。
