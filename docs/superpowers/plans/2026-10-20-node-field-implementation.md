## 范围与接口

1. `GalaxySpatialField.ts`：输入 layoutVersion / snapshotHash / seed / viewSize（世界空间宽度，非屏幕像素）/ positions；复用 `spatialPoint` 世界坐标。固定128²网格、双线性沉积、可分离高斯平滑、累计分布采样。只保存最近一次输入，逐项精确比较，改变坐标/身份/版本均失效。
2. `generate.js` / `particles.js` / `background.ts`：保留旧采样和 tint/FAMILIES；非远景球壳的现有预算混合采样，不增加点数。默认 legacy；`graphSpace=node-field-v1` 显式候选。背景几何只随场变化替换属性，resize/相机不重建。
3. `GraphPanorama.vue`：在布局准备完成后传共享世界坐标，初始化与加载竞态均覆盖；失败释放候选场并关闭旧数据展示；技术折叠区说明事实/布局/装饰边界及回退。
4. 自动验证：先测分布随节点移动、确定性、输入不变、空集回退、坏坐标、全部历史节点及缓存失效；再执行真实SFC生命周期、全前端、类型/构建与必要离线图谱回归。
5. 实机：历史图相同相机/DPR/冻结时钟新旧截图，交互/拾取/关系/回退/FPS；只读取得71/52私有产物作算法检查。本分支没有真实图加载链路，不将算法检查冒充正式Vue真实图验收。

## 候选工程取值及风险

基础分布保底45%，节点密度55%；core保底75%，避免稀疏数据抹掉银河核。核宽11世界单位，128²网格边界含基础200宽与节点外缘4σ。平滑节点密度同时插值展示深度均值，节点位置本身完全不改。参数为待视觉验收工程候选，不能解释成分类/社区/相似性。

重点核查：稀疏/极端重叠不塌缩；世界范围resize不变；输入相同但坐标变化不能缓存命中；初始化早于/晚于数据均绑定；失败/卸载不残留旧资源。
