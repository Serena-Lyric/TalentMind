## 二·五、工程经验（与模块职责无关，A / 本地运维参考）

整合过程中踩过、但与各模块二次开发职责无关的工程问题，归档于此（笔记.md 第六节引用本处）：

1. **FastAPI 路由顺序**：静态路径（如 `/jobs/export`）必须注册在参数路径（如 `/jobs/{job_id}`）之前，否则 int 参数先匹配返回 422。
2. **表单上传**：FastAPI 处理 `FormData` 需要 `python-multipart`（已加入 requirements）。
3. **路由前缀**：`APIRouter(prefix=...)` 与 `include_router(prefix=...)` 只在一处设置，避免产生 `/api/api`。
4. **`import_exchange.py` 语义**：job_definition/job_skill 为**全量重建**（先清空再写，M2 产出是权威岗位集合）；CRUD 手动新增的岗位在重导后会被清除。
5. **进程清理**：Windows 下 Ctrl-C 可能不终止 uvicorn/vite 子进程，用 `Get-NetTCPConnection -LocalPort <port>` + `Stop-Process` 清理（AGENTS 规则）。
6. M2 完整回包接入后图谱使用 `job:<m2_job_id>`、`skill:<canonical>`、`industry:<slug>` 稳定节点键，Neo4j 嵌套 evolution 属性序列化保存。
6. **M2 LLM 配置（2026-10-15 代码核查）**：`job_analysis/config.py` 只通过 `os.environ` 读取 `LLM_API_KEY/LLM_BASE_URL`，未自动加载 `.env`；与 FastAPI 的配置读取方式不同。
7. **Neo4j 导入是破坏性重建**：当前 `import_graph.py` 会先 `MATCH (n) DETACH DELETE n`，再 MERGE。只在明确授权的隔离/恢复实例执行，不能当成日常非破坏同步。
8. **前端联调**：vite dev 的 `/api` 默认代理 18000；`package.json` 的 build 已执行 `vue-tsc --noEmit && vite build`，无需重复接入。
9. **vue-tsc 版本兼容**：`vue-tsc 1.8.x` 与 TypeScript ≥5.4 不兼容（`Search string not found: /supportedTSExtensions/`）；前端需锁 `typescript ~5.3.3`，`build` 已改为 `vue-tsc --noEmit && vite build`。
10. **change_log 导入**：`import_change_logs` 曾引用 DDL 不存在的 `object_type` 列且 M2 `job_id` 为 job_name、DDL 语义为 id；空数据不触发、非空即崩。已修复（job_name→id 解析 + 全量重建），改导入层必须对照 DDL 逐列核对。
