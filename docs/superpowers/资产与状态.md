## 二·五、工程经验（与模块职责无关，A / 本地运维参考）

整合过程中踩过、但与各模块二次开发职责无关的工程问题，归档于此（笔记.md 第六节引用本处）：

1. **FastAPI 路由顺序**：静态路径（如 `/jobs/export`）必须注册在参数路径（如 `/jobs/{job_id}`）之前，否则 int 参数先匹配返回 422。
2. **表单上传**：FastAPI 处理 `FormData` 需要 `python-multipart`（已加入 requirements）。
3. **路由前缀**：`APIRouter(prefix=...)` 与 `include_router(prefix=...)` 只在一处设置，避免产生 `/api/api`。
4. **`import_exchange.py` 语义**：job_definition/job_skill 为**全量重建**（先清空再写，M2 产出是权威岗位集合）；CRUD 手动新增的岗位在重导后会被清除。
5. **进程清理**：Windows 下 Ctrl-C 可能不终止 uvicorn/vite 子进程，用 `Get-NetTCPConnection -LocalPort <port>` + `Stop-Process` 清理（AGENTS 规则）。
6. **M2 LLM 配置**：`job_analysis/config.py` 通过 `python-dotenv` 读取 `backend/.env`（`LLM_API_KEY/LLM_BASE_URL`，gitignore 保护）。
