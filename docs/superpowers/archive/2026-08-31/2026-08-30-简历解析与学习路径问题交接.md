## 4. 待处理问题及复现证据

### 4.1 上传后其他页面看似不能跳转

复现：

1. 打开 `http://127.0.0.1:18080/#/resume`；
2. 上传上述合成 DOCX；
3. 等待“已解析完成”；
4. 点击“生成学习路径”或侧边栏“JD岗位管理”。

现象：

- URL 会变化，例如 `#/learning?job=<岗位ID>` 或 `#/jobs`；
- 页面标题会变化；
- 页面正文仍停留在 Resume 页面。

浏览器控制台实际错误：

```text
Unhandled error during execution of mounted hook <AbilityRadar>
TypeError: Cannot read properties of undefined (reading 'push')
at echarts radarLayout
```

根因链：

1. `ResumeDiagnosis.vue` 的 `radarData` 始终是空 dimensions、空 jobStandard、空 personalAbility；
2. `AbilityRadar.vue` 仍使用空 indicator 和空 radar value 初始化 ECharts；
3. ECharts radar layout 抛出运行时异常；
4. 路由状态已更新，但 RouterView 组件切换处于异常状态，表现为 URL/标题更新而正文不变。

另有非阻塞警告：

```text
Failed to resolve component: MagicStick
```

原因是 `ResumeDiagnosis.vue` 模板使用了 `MagicStick`，但当前 import 没有导入它。

### 4.2 “生成学习路径”按钮无效

`ResumeDiagnosis.vue` 的 `goToLearning()` 只做：

```text
弹提示 → router.push('/learning?job=...')
```

没有调用生成 API。当前正式 `Learning.vue` 只显示空态，后端也没有正式 `/api/learning/generate-path` 路由。

这需要 M5、M4、A 共同确定：

```text
简历技能 + target_job_id → pathfinder → path/level/tip → Learning 页面
```

不要只在前端恢复旧 Mock 学习路径。
