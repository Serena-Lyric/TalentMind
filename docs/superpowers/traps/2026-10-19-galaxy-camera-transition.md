# 三维银河相机过渡、微抖与派生端点

## 症状

- 相机定位飞行中拖动会跳到旧终点；切换到当前可见的搜索结果后，旧定位仍将目标移出屏幕。
- 1px 指针微抖被视作单击，却已经改变相机姿态。
- 可选派生层在原始邻域选择后可能画出指向隐藏星体的线。
- 浏览器首次编译关系 shader 报 GLSL 保留字 `active`；初稿全景用包围球适配导致银河太小且环绕目标偏离原点。

## 根因

camera-controls 3.1.2 的 `stop()` 会将当前状态复制为旧动画终态，不是“原位中断”。只改显示相机或使用 end target 都会被控制器覆盖。三维 pointermove 在拖动阈值前已调用 orbit；派生线与节点未共享 focusIds 条件。GLSL 保留字不能直接从 JS 变量类推。默认全景与“全部关联”的面板适配属于不同镜头语义。

## 修复

基础相机归控制器管理，显示相机仅叠加本地滚转；中断先读取当前 position/target，再同步控制器当前/结束状态。主动搜索即使当前已可见也中断旧飞行。拖动超过 3px 才移动相机。派生线两端均须满足真实节点的可见条件。关系 shader 改用 `emphasis`。默认 R 恢复原点环绕与默认姿态，关联适配独立保存/返回完整状态。

相机、实际 Vue 事件链和派生过滤均增加回归；过渡、微抖与默认视角用失败测试复现后修复。浏览器核验 shader、环绕、滚转和原边高亮；性能结论与剩余边界见 P2.3 报告。

## 教训

查安装包的实际实现，不能靠方法名推断行为。姿态只能有一个写入者；投影、拾取、标签和边端点共享同一相机。异步相机测试必须覆盖过渡中的用户操作。浏览器重建后先核对实际加载的 bundle，再将采样标为最终版本；冷启动、稳态、重绘、首响应及完整过渡分别计量。

补充：控制器最后一帧可能在 `update()` 返回 false 时吸附到精确终态；显示相机不能只按该布尔值更新。新增失败回归后比较实际 position/quaternion 变化，确保最后一帧也同步。稳定默认姿态及带滚转/平移的浏览器单次往返均逐项相等。搜索显式提交同步更新知识层，避免额外等一帧；高频拖动仍按 rAF 合并。
