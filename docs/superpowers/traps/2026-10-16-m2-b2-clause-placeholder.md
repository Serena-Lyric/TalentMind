# 技能陈述占位符碰撞与重复成员伪组合

## 症状

合成反例“必须掌握 S 和 Python”可能把未知文字 S 当成规则内部技能占位符，错误生成仅有一个已知成员的必备组合；“Java 或 Java 至少掌握一种”可能伪装成两个可选技能。

## 根因

原型语法用普通字母 S 替换已识别技能，原文中的同字符与内部 token 无法区分；组合只看句式，未核对 canonical 成员是否互异。

## 修复

先加入三项回归，实测 2 failed / 66 passed。改用非普通文字 token（原文本身含此 token 时保守 uncertain），组合要求至少两个不同 canonical；不可靠时保留原文、原因与 incomplete，不强建关系。修复后 B2 68 passed，未修改正式词典。

## 教训

引文匹配只能证明出处。结构替换不能把未识别文字变成已识别技能；组合验证必须同时检查语法、成员数量与成员身份。合成反例通过不等于真实语义准确率。
