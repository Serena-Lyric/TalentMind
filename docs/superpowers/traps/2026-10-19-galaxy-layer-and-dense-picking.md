# 银河集成：画布矩形错位与密集节点命中

## 症状

正式 Vue 银河装饰层与知识层的中心/平移不完全重合；密集区点击 Python 的屏幕中心却选中邻近技能。候选布局失败时，中央回退链接无法点击。

## 根因

- WebGL 的 CSS 覆盖整个 section，但 renderer 使用避开 56px 页头后的容器尺寸；setSize(...,false) 不更改 CSS，背景被纵向拉伸。
- 旧命中逻辑反向遍历数组，返回命中半径内第一项；大量真实节点相距不足7px时，数组末项夺取另一节点身份。
- 错误容器原为纯文字，设了 pointer-events:none；加入交互链接后未恢复事件。

## 修复

- 两层使用同一 top=56px 与剩余高度；真实浏览器先复现 aligned=false，再核对两层 DOM rect 完全相同。
- 在实际绘制的节点中选择最近屏幕中心，距离相等按ID稳定裁决；新增近邻抢占回归先失败后通过。真实浏览器再次点击 Python 后 selectedId=skill:python，transform逐项不变。
- 错误链接显式 pointer-events:auto。生产预览临时移走构建输出布局文件，候选拒绝加载；点击中央回退，旧 Canvas 独立加载7845/11412。随后重新构建恢复输出，未改原快照。
- 图层和候选产物变更后必须重新加载生产包；开发插件监听产物变更重启，避免内嵌摘要与新文件错配。

## 教训

Canvas/WebGL与Vue状态的单元测试不能证明真实DOM投影或命中体验。必须核对实际矩形、真实密集节点、参数回退和加载失败路径。摘要校验不能为普通HTTP LAN跳过；当前明确要求localhost/HTTPS。
