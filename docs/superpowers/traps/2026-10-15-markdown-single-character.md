# Markdown 校正段落被拆为单字符行

日期：2026-10-15。

## 症状

README、Agent 入口、资产说明中的日期、中文和代码路径逐字符换行；Agent 交接与资产文件的旧引用还被插入段落打断。

## 根因

六份文件含相同的 717 字符校正块，每个字符独占一行。可以确认损坏形态，无法从当前文件证明最初写入工具或具体语句，故不推断是哪次脚本造成。

## 修复

扫描全部 Git 跟踪 Markdown，对连续不少于 20 行、每行至多一个字符的块逐字拼回；确认六块均以同一 2026-09-05 校正标题开头，再恢复两个引用段落边界。除将“当前状态”明确为历史基线和隔离测试指引外，不重写原数字或原意。重新连接被插入块打断的两处 09-04 引用。随后按代码修正文档当前说明，历史段另行标注，不用现值覆盖历史数字。

## 教训

批量写文档后须检查 diff 和 Markdown 结构，不能只检查文件存在。修复能还原的字符，不猜测未知原文；数据库计数、文件计数、演示指标与历史测试结果应区分来源及日期。
