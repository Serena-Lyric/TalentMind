# 图谱外壳：共享顶栏与视口高度的路由边界

日期：2026-10-17；范围：Issue #26 P0，仅图谱页面外壳。

## 症状

1600×900 原主窗 top/bottom=84/858，左导航=18/882。直接隐藏顶栏仍不足以对齐，子图谱有独立的视口高度计算。审查另指出 `/graph/`、`/GRAPH` 合法路由变体：精确比较 path 会漏判，顶栏恢复时新图谱高度使文档增加至 990px。

## 根因

全局 74px 顶栏、页面 padding 与组件 `viewport - 126px` 高度分别计算；Vue Router 默认允许尾斜杠与大小写变体，路由匹配成功不保证原始 path 字符串相等。

## 修复

共享外壳按既有 `route.name === 'Graph'` 隐藏顶栏并设置 18px 上下 padding。Graph 包装页用 `viewport - 36px`（dvh + vh 回退），scoped 深度选择器覆盖子图谱高度；保留既有最小高度与内部菜单。1600×900、1920×1080 实际浏览器测得上下边缘一致、无溢出；合法变体复核通过。登录、其他页顶栏和正式图谱组件逻辑不改。

## 教训

路由专属外壳使用稳定路由身份。布局验收测量完整主窗而非内部详情，并等待过渡结束；短屏需保留必要滚动，不能以隐藏 overflow 掩盖不可达内容。证据见 `docs/review/Career-Nebula-issue-26-P0.md`。
