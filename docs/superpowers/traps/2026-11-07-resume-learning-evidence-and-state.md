# 简历证据、学习路径与异步状态

## 症状

- 无日期工作经历抛出 `KeyError: description`；普通学校/分行教育漏失；DOCX 表格正文重复且离开原章节顺序。
- C++ 边界漏提取；岗位别名与必备/加分交叉重复计数；展示分随机抬到 90 以上。
- 空岗位要求被判达标，软技能未提及被当作缺乏；零技能简历无法生成路径。
- 切换岗位不重新生成；旧上传/路径请求迟到后覆盖当前状态，失败页一直显示生成中。

## 根因

解析依赖固定学校名单及带日期首行，章节识别使用任意子串；表格追加两遍。英文 `\b` 不适用于以符号结束的技能。匹配在 canonical 归一前比较，学习列表按原名而非 canonical 去重。展示层沿用演示分和能力断言，异步请求没有当前请求身份。

独立审查还复现了标题收紧后的编号/双语标题回归，以及日期字符串比较把 `2024.9` 排在 `2024.10` 之后的问题。标题需受限规范化后再做完整匹配；日期先解析年月，再按结束时间/至今与开始时间排序。

## 修复

补无日期经历状态，完整标题边界及同行正文；合并分行教育并采用学校后缀识别。DOCX 顺序遍历段落/单元格；上传限制 10MB、DOCX 解压总量 40MB、严格格式与 UTF-8 文本。旧 DOC 显式提示转换，不再假称 mammoth 支持二进制 DOC。

匹配/学习共用 canonical，必备优先、稳定输出实际规则分；覆盖率只表示字段存在。软技能待核实、空要求信息不足；技术学习项附练习及完成条件。前端监视岗位与当前简历，递增请求身份防迟到响应，并显示错误/重试。

## 教训与验证边界

“未提及”与“不会”、“命中”与“掌握”、“规则分”与“准确率”必须分别表达。测试使用合成文本、内存 DOCX、禁止数据库连接的上传边界及真实 Vue 响应式脚本；无生产数据修改。扫描件 OCR、复杂多栏 PDF 和真实简历效果不在本次已验证范围；算法仍是规则提取和启发式学习顺序。
