# 图谱首帧、粒子构建与关系强调

## 症状与根因

进入图谱时重模块载入和页面过渡留下空档。背景初始化同步生成 214200 个粒子，绑定知识场时再次构建，着色循环反复分配颜色对象。背景旋臂与节点引导区域直接切换分布，视觉连接较硬。

## 修复

- 路由组件提供即时加载壳，首帧准备状态持续至实际绘制回调，错误状态单独显示。
- 历史图与布局并行读取，摘要和身份绑定验证后的输入在模块内缓存，每个视图取得深拷贝。显式刷新强制读取，当前失败请求清缓存，旧请求失败通过 Promise 身份检查保护新缓存。
- 粒子生成复用颜色对象，生产路径使用 module Worker 和 Transferable 缓冲区。初始化同一轮的字段绑定合并，刷新终止旧 Worker，卸载取消定时器并终止 Worker，世代判断拒收迟到结果。
- 节点场使用连续坐标混合，背景透明度调整，知识节点增加方向光、高光和轮廓光。选中原关系使用现有 Three.js Line2，48 段曲线和屏幕空间线宽，端点颜色沿曲线插值。过滤、清除、换数据同步撤销强调。

## 来源与验证

参考 Three.js 官方 fat-lines 与 3d-force-graph 的 custom-node-geometry/curved-links 示例。使用项目已有 Three.js addon，源码许可沿用依赖 MIT。2026-11-07 GitHub API 查询 Three.js 为 117733 星，3d-force-graph 为 6543 星。[Three.js 宽线](https://threejs.org/examples/webgl_lines_fat.html)、[节点几何示例](https://github.com/vasturiano/3d-force-graph/tree/master/example/custom-node-geometry)、[曲线关系示例](https://github.com/vasturiano/3d-force-graph/tree/master/example/curved-links)。

构建入口壳约 2.34KB，主要渲染模块约 812KB，分包体积告警继续存在。

同机 Node 单次粒子生成观测约 1284ms → 503ms，粒子数量相同。此数字仅描述生成函数。浏览器 Worker 实测约 566–617ms，首帧约 1239–1445ms，包含当前浏览器约 1 秒的帧调度间隔，不能用该观测推算正常前台 FPS。主线程提交耗时与 GPU 完成时间分别理解。

回归覆盖缓存对象隔离、刷新失败重试、Worker 卸载/刷新迟到回包、宽线过滤及旧高亮清除。浏览器验证搜索、222 条 Python 直接关系、缩放/近景、单边高亮、刷新、离开与重新进入，节点 7845 / 关系 11412 保持，未观察到 WebGL 错误。

## 教训

加载反馈以实际首帧为结束条件。总构建耗时、主线程阻塞和浏览器节流需要分别测量。装饰异步化必须覆盖取消与释放，视觉更新继续保留数据校验及真实图谱的独立加载边界。

## 宏观视角后续修订

用户反馈宏观旋臂与星尘仍突兀。四视角和类型开关对照发现，全局随机节点场混合、固定雾团、局部配色斑块、节点周边装饰粒子及密集节点高透明度叠加，都会形成脱离旋臂的亮团。

本轮改为 `local-arm-field-v3`。双线性 KDE 梯度只牵引附近背景粒子，水平每轴最多 2.5、垂直最多 0.45，中心与远处粒子使用基础分布。雾层与星尘共享四臂及指数薄盘，增加臂间底层，统一径向色温和外缘衰减。宏观节点装饰光晕连续减弱，密集普通节点使用连续透明度调节，选中、悬停、搜索及关系焦点保持保护。

默认斜俯视、正俯视、低角度侧视及另一侧斜俯视均完成浏览器截图复核。类型全部开启时为 7845 个节点、11412 条关系，Python 搜索仍得到 87 个匹配及 222 条直接关系。最终完整加载无新增控制台错误。259 项前端测试、类型检查和构建通过，独立 P2.5 7 项复核通过。

截图和相机姿态位于私有 `data/local/ui-qa-20261107/galaxy-macro-*`。前轮随机位置插值方案由本段替代。视觉验收须先做背景/节点分层对照，再用多角度检查最终叠加效果，单张近景不能证明宏观协调。

用户随后确认需要尽量保留原有颜色。统一冷蓝方案显得平淡，现恢复既有 FAMILIES 蓝紫/青蓝色值、淡暖核心，使用更宽的颜色过渡和适度提高的粒子透明度。局部旋臂场继续使用 v3。斜俯视、正俯视、侧视已复核，截图为私有 `galaxy-palette-*`。后续调整优先沿用这组原配色。
