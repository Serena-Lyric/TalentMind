# 银河粒子层次与渲染目标纹理

- **症状**：近景尘埃尺寸趋同，薄雾结团；四条窄臂间断裂。尝试扩大雾粒子后近景填充开销明显增长；新增 ShaderPass 最初告警且雾光缺失。
- **根因**：共用窄臂采样、26 个等节奏雾结、相近尺寸/透明度和强亮度噪声。扩大 sprite 面积会增加 overdraw，即使粒子数量不变也会变慢。ShaderPass 会 cloneUniforms，而 RenderTarget 的纹理不能在此克隆，原值被置空。
- **修复**：保持总数与业务节点，分步重分配稀疏圆盘/臂翼；拆分 fine/haze 样式，近景尺寸与淡出集中配置。未分辨雾光独立半分辨率渲染，实体和细尘全分辨率，在线性色彩阶段合成后走原 Bloom。ShaderPass 构造时纹理值为 null，构造后绑定真实 target.texture；新增失败反例后修复通过。配对浏览器图和实际帧时间见 P1-A.1 报告。
- **教训**：先改分布和层次，不能用加数量/加 Bloom 掩盖；尺寸上限也不能一刀切压暗光雾。性能同时核查远近景，理论像素覆盖不等于 GPU 时间；实际 GPU 编译/控制台验证不能由构建替代。
