# 页面可读性与装饰避让

## 症状 → 根因

- 学习路径的人物覆盖重新生成按钮和目标岗位：装饰绝对定位在右上角，布局没有预留对应空间。
- 采集正文行距紧密：`font: 13px/1.8 inherit` 是无效的混合 shorthand 声明，字号和行高未按预期生效。
- 岗位空搜索有 No Data 和中文提示两份空态：组件默认空态与表格外自定义空态并存。
- 同一采集异常重复显示：stop_reason 与 last_error 未去重直接拼接。

## 修复

保留原有主题和素材，为学习页装饰留出空间，目标信息允许换行；字体、字号、行高分别声明；自定义空态进入表格 empty 插槽，并使用组件中文语言包；错误按原始原因去重，再翻译明确的迁移阻塞原因，不执行迁移。

## 验证与教训

真实浏览器使用合成简历验证上传、预览、PDF 导出与学习路径。修复后宽、窄窗口下按钮与装饰矩形无重叠，页面无横向溢出；原文行高为 25.2px。空搜索仅显示一份中文空态。新增错误提示回归先失败后通过，前端全套 255 项通过。

组件逻辑通过不能证明视觉可用；装饰即使不拦截点击，也可能遮住文本。测试现场必须区分 UI 失败、数据为空和生产配置阻塞，不能为了“全绿”执行未经许可的数据迁移。
