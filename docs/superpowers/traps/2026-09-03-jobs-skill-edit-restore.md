# 2026-09-03 前端重整后 JD 岗位详情技能增删丢失：恢复旧版可编辑交互

## 症状

JD 岗位管理页“查看详情”弹窗中技能只能只读展示；旧版每个技能末尾有 x（删除）、所有技能之后有方框 +（新增）的增删交互丢失，无法完成技能维护（增删改查中的增删）。

## 根因

2026-08-31 前端完整重整按“展示页”重写 Jobs.vue 时，只迁移了只读技能标签，未迁移旧版 editor 的技能可编辑交互；同时后端 PUT /jobs/{id} 是全量更新语义（会整行覆盖），但 GET /jobs/{id} 未返回 job_name，前端若直接 PUT 既缺稳定 key 又可能覆盖无关字段。

## 修复

- 后端 job_detail 响应补充返回 job_name（保持 job_definition 稳定 key，不触发改名）。
- 前端详情“技能要求”按旧版样式恢复：每个技能标签可关闭（x）删除；末尾方框“+”按钮展开输入，回车新增。
- 保存时做“新增/删除”差异计算，只把变化落到 required_skills/bonus_skills（保留原有必备/加分分类），调用 PUT /jobs/{id} 持久化并刷新列表。
- 前端 Job 类型补齐 job_name/required_skills/bonus_skills/scenarios/quality。

## 教训

前端重整不能只保“展示”而丢既有编辑交互；接入真实写接口前，先核对更新端点是全量还是局部语义、详情是否返回稳定 key，避免整行覆盖或把关联 key 改名。
