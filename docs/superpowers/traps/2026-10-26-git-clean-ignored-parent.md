# Git clean 忽略父目录范围提升

## 症状

仓库维护时只拟清理 `frontend/node_modules/.vite`，但 `git clean -ndX` 的预览已提升为整个被忽略的 `frontend/node_modules/`。未对预览结果与授权清单逐项比对便执行，导致前端依赖部分删除；Windows长路径又使删除返回错误。

## 根因

仅验证了传给Git的子路径，忽视Git对整个忽略目录的遍历/路径匹配结果。预览本身不是安全保证，必须核对预览实际要删除的对象。

## 修复

按现有 `pnpm-lock.yaml` 强制重新安装前端依赖，保持源码及锁文件不变，再验证TypeScript和Vite生产构建。未以恢复为由操作业务数据库或原始数据。此记录不授权继续删除依赖。

## 教训

清理预览必须严格落在逐项允许的路径内；若子路径被提升到父依赖目录，应立即中止。重建依赖与清理缓存是不同操作，不能把 `node_modules` 当作已获缓存清理授权。长路径失败也不能当作“没有删除任何文件”。
