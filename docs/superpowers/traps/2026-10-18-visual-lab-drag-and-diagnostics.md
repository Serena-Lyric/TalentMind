# 银河实验：往返拖动误点、诊断泄漏与后台采样

- **症状**：拖动旋转后回到起点会选择/清除星体；生产包仍包含 GPU/UA、帧历史与运行时 DOM 数据采集；后台标签页短时键盘检查漏帧，帧率异常低。
- **根因**：点击仅比较起终点，未记录手势曾越过拖动阈值；DEV gate 只包住面板导入，未包住采样；自动化新建标签页不自动激活，rAF 受后台/最小化节流。
- **修复**：pointermove 记录整次手势是否越过 5px，往返不点选；实际 createCamera + OrbitControls 回归先失败 1 次，再修复通过。环境查询、帧采样、快照和面板全部移入 DEV 诊断模块及分支；生产构建扫描核对。用户切到前台后重跑页面交互与性能采样，后台失败记录不冒充前台结果。
- **教训**：拖动手势按完整轨迹判定；诊断的采集和展示都须受同一环境边界约束；真机 FPS 必须记录可见性、视口、DPR 与设备，DPR 浮点值的 canvas 尺寸按渲染器取整规则断言。
