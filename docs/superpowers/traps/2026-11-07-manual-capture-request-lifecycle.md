# 普通浏览器采集：重复点击与不确定提交

## 症状

扩展弹窗在保存配对信息完成后才禁用按钮，快速连续点击可能发出重复请求；关闭重开弹窗时，后台也没有进行中的采集互斥。回环服务不响应时没有请求期限；保存失败发生在 try 外，用户得不到可恢复的错误状态。

## 根因与修复

- 弹窗在首次 await 前锁定操作，将保存和发送放入同一 try/finally。后台另设单个进行中请求门禁，覆盖多个弹窗实例；成功、页面拒绝、配对缺失和服务错误都释放锁。
- POST 及响应正文读取共用 15 秒 AbortController 期限，结束清理计时器。不自动重发，不自动访问平台。
- 超时、连接错误及无效 JSON 明确表示提交结果未知。客户端中止不证明数据库没有写入，应先在控制台核对本轮结果，不能将网络错误等同于可安全重试。

## 验证与边界

Node 24 执行 `node --experimental-strip-types --test tests/bridge*.test.ts`：21 项通过。覆盖后台并发拒绝、请求与正文超时、连接/响应正文 JSON/扩展消息通道错误、服务拒绝、配对缺失、弹窗保存失败恢复，以及既有提取和验证阻断回归。Chrome API、页面和传输为模拟边界，不是真实扩展安装、招聘网站或数据库验收。锁为 service worker 内存态，不提供跨重启的 exactly-once 保证。

未改权限、平台范围、身份和正文门禁、持久化契约或 DDL。真实浏览器到隔离数据库的有界验收仍待可访问环境；历史数据库数字和旧测试结果不作为本次证据。
