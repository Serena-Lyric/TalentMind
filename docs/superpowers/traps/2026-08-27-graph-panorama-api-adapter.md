# 2026-08-27 图谱前端适配后画布空白与视图无数据

## 症状

将输入包中的 `GraphPanorama.vue` 接入正式前端后，页面统计能读到 97 个节点/222 条边，但图谱画布初始空白；星云图没有技能连线，树状图和环形图在正式数据下没有可视内容。

## 根因

1. 正式路由中的 `el-main` 没有给包装后的图谱组件提供确定高度，组件内部 `height: 100%` 计算为 0。
2. 后端图谱 API 将关系类型统一返回为小写 `requires`，输入包星云布局只识别大写 `REQUIRES`，导致岗位与技能没有建立布局关系。
3. 正式图谱当前没有 `industry` 节点，输入包树状图/环形图只按行业节点构建，数据为空时自然显示空白。

## 修复

- 给正式 `Graph.vue` 包装页增加视口相关的最小高度；
- 在前端适配层把 `requires`/`job-skill` 统一映射为布局算法使用的 `REQUIRES`；
- 树状图在缺少行业节点时回退到“岗位 → 技能”；环形图回退到“岗位/技能”节点分布；
- 刷新图谱时等待真实数据加载完成后再重建图表，并释放旧实例；
- M3 builder 支持传递 `job_name_zh`，Neo4j 导入支持写入 `name_zh`，为 M2 新回包预留正式字段。

## 教训

模块交接不能只检查 TypeScript 构建；必须同时核对 CSS 尺寸、API 枚举大小写、缺省节点类型和真实数据下的每个可视化分支。
