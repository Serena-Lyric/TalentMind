## 6. 源码、环境与危险入口核验

- 从 Git bundle 恢复出的 V1 源码，数据库连接指向不可达测试地址，仅运行非集成测试：**222 passed / 2 skipped / 23 deselected**，190 条依赖弃用警告；未运行会改演示库的集成测试。
- 恢复目录中的前端复用已安装依赖，直接运行 `vue-tsc --noEmit` 与 `vite build` 成功；仍有 >500 KB chunk 警告。`pnpm run build` 在新路径复用依赖时试图自动重装并因无交互终端退出；未接受清空依赖目录。本轮未验证从零在线安装依赖，也未运行完整浏览器业务流程。
- 原版 719/243 回包与 V1 717/275 不同。`import_all()` 默认从 `input/岗位数据-新一代与现有/` 读取，删除后重建分析层；`test_integration_mvp.py` 的幂等用例直接调用它。
- `import_graph.py` 开始即 `MATCH (n) DETACH DELETE n`；图谱集成测试也直接调用它。历史交接中“幂等”不意味着无破坏性。
- 旧 `app/graph/builder.py` 不能作为当前完整图谱生成器；新电脑应优先恢复已核验的 graph.json、原生 dump 或冷卷。
- 保留 `PAUSE_COLLECT`。本机未查询到 `TalentMindCollect` 任务，未擅自重建；日常恢复无需采集任务或浏览器登录态。采集页会准备浏览器并尝试单轮，恢复核验时不进入该页。
