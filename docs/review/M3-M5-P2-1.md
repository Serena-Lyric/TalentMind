- 度一技能仅远景折叠；搜索、近景与选中邻接恢复。共享技能位置使用全部直接关联岗位的重心，保存全部 adjacent_jobs 和 communities；不因首次归属丢边。无相似边的孤点 community=null，不强制归类。
