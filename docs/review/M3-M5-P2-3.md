## 相机、空间与渲染

采用官方 **camera-controls 3.1.2 / MIT**，peer `three >=0.126.1`，与现有 Three 0.180.0 兼容。[依赖来源](m3-m5-p2-3/dependency-provenance.json)、[许可证](m3-m5-p2-3/camera-controls-license.txt)。没有假设其原生支持 roll。

控制器独占基础相机，显示相机复制基础相机后叠加本地 Z 轴滚转。控制器不连接 DOM，由一个输入适配器管理左拖旋转、右拖/屏幕 WASD 平移、Q/E 左右滚转、滚轮缩放、R 全景。平移使用滚转后显示相机的 right/up；修饰键、输入框、输入法、可交互控件受保护，失焦/隐藏/卸载清除按键。

默认绕银河原点观察，无自动旋转。单击、关闭详情、原边列表跳转均不主动移镜头。主动搜索和全部关联才可平滑移动；保存位置、目标、距离、up、四元数、FOV、zoom 与 roll。新目标、手动操作与返回会正确中断旧飞行。默认及非零滚转/平移的浏览器单次往返，完整状态逐项一致，最大差值 **0**；过渡中断及最终吸附另有回归。

`display-depth-v1` 在运行时从稳定 ID 和原布局 x/y 生成确定性展示厚度，原 layout-v1 文件不变。它不是经验证的语义距离。装饰盘的星核、旋臂与厚度使用既有独立生成器；真实星体采用原 P2.2 类型权重、锐核/光晕精灵和尺寸上限，GPU 批量 Points 提交。线为逐原边的三维二次曲线 LineSegments，端点及 sourceIndex 保持，单边高亮用 uniform，不重新建立全部曲线。

装饰、知识星体和关系使用同一透视显示相机；标签与拾取来自该相机的同一次投影。背后/近远裁剪点不能被拾取，重叠命中按屏幕距离、深度、稳定 ID 决定。三维视锥裁剪独立于二维回退的裁剪，不能继续用原平面判断旋转后的边。诊断intersecting按三维曲线凸包AABB做保守视锥判断，表示候选，不是GPU像素可见线数；不以它替代原边总量。
